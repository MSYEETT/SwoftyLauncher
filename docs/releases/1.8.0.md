# 1.8.0

Swofty Launcher for F1 25 1.8.0 adds the **Shaders** page: a library of effects, configs that choose effects and set their options, an editor that checks a config as you type, and a preview on a short clip of the game. Realistic is a new config, and PolyphoniX Native is now a config.

## Shaders

- The **Shaders** page sits under **Addon Browser**. The right side lists configs: **Off**, **Your configs** and **From addons**. The left side is an **Editor** or a **Preview**.
- A config is a text file. Each `[table]` is an effect and the keys under it are its options:

```toml
name = "Evening"

[look]
brightness = 125
white_balance = 5600

[glare]
bloom = 35

[vignette]
amount = 0.3
```

- The Editor checks the config as you type, with squiggles, a problems list, completions, hover help and quick fixes. A config with an error is not applied. A valid config of yours saves by itself and, when it is active and the game is running, changes the picture in game straight away.
- The Preview plays a short clip with the config applied, with a scrub bar and a **Compare** line that splits original and result. The clips are dry and wet races at Melbourne from onboard and chase cameras.
- The **Documentation** tab lists every effect with its options, defaults and ranges, and copies an effect's table into your clipboard to paste into a config.
- The in-game key that turns the shaders on and off is set on the page. The default is `B`.
- With shaders off, the game gets no shader files and the core arms none of its shader hooks, so playing without shaders costs nothing.
- The effect library has `auto_hdr`, `ambient_light`, `color_mod`, `contrast_stretch`, `cbs`, `perspective`, `curved_monitor`, `glare`, `look`, `vignette`, `sharpen` and `grain`. [Effect library](/reference/addons/shader-effects) lists every option.
- `swofty shaders` manages configs from the command line: `list`, `effects`, `show`, `lint`, `use`, `new`, `copy`, `rename`, `delete`, `import`, `export` and `key`.

## Realistic

- **Realistic Shader** is a new addon with one config: flatter contrast, calmer reds and HDR-like highlights, with bloom and eye adaptation. Find it in the Addon Browser under Shaders. The config leaves `perspective` and `curved_monitor` switched off; they suit a 120 degree field of view and a 1500R monitor.

## PolyphoniX Native

- PolyphoniX Native 0.4.0 is a config. It holds the same glare and look values, appears on the Shaders page and is not turned on by installing it. The addon's own toggle key is replaced by the Shaders page key.

## Addons

- An addon can bundle configs with `shaders` and effects with `effects`. Its configs stay on the Shaders page while the addon is switched off, and go when the addon is deleted. [Shader configs and effects](/reference/addons/shaders) has the manifest and the effect format.
- An addon can force its config. The Shaders page then shows "You have an addon which forces this shader configuration" and locks the list.
- An addon that holds only shader configs and effects has no on/off switch on the Addons page. It shows a **Shader config** chip with **Open in Shaders**.
- Effects can read up to 32 option values, `option(0)` to `option(31)`. Passes in an addon's manifest keep working and run after the config's effects.

## Fixes

- An addon whose description is too long for the game's addon list no longer stops the game from launching ("string longer than 255 bytes"). The description is cut short with "…" in game.
- Shader configs and effects go into a packed `.swoftyaddon` (`tools/pack_addon.py`).
