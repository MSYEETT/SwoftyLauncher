# 1.8.1

Swofty Launcher for F1 25 1.8.1 makes the Shaders page's Preview work on Windows, fixes existing careers that crashed when a session started after updating to 1.8.0, frees car ids that removed addons still held, and gives a third car in a team its team's AI racing line.

## Shaders

- The Preview on Windows no longer fails with "SPIR-V CodeGen not available". The shader compiler in the Windows and Linux downloads now builds effects for the Preview. Shaders in game were not affected.
- A shader compiler that can't build effects for the Preview gives one message on the Preview instead of one per effect.

## Careers

- Some existing careers, such as Classic Seasons careers, crashed when a session started, with cars missing from the grid, after updating to 1.8.0. They load again.
- A third car in a team uses its team's AI racing line when the game has none for it.

## Addons

- Play no longer stops with "has no free stat_id" when the car package table is full. Car ids held by addons that no longer add those cars are freed for new car addons.
